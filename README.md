# Yopresencia Psicología

Sitio web Angular con páginas independientes, formulario de contacto, autenticación y panel de administración respaldados por PHP y MySQL.

**Instalación y seguridad en XAMPP:** consulta `README-SEGURIDAD-XAMPP.md`.

Requisitos: Node.js/npm y XAMPP con Apache, MySQL y PHP PDO MySQL habilitado.

Ejecutar frontend desde esta carpeta:
```bash
npm install
npm start
```

Abrir `http://localhost:4200`.
